Delete from the iPhone

  • Favourites are never deleted (nor their Live Photo videos, edit data or edited versions). They are read from the phone's Photos database first; if that can't be read, nothing is deleted.
  • Each file is checked just before it is deleted: the server must have it, with the same size and checksum. Anything that fails the check is kept.
  • This cannot be undone. The only copy left is the one on the server.
  • Deleting this way goes around the Photos app, so Photos may show blank placeholders or the phone may refuse some files. Try a few files first.

The server check is skipped: these files are NOT verified to be backed up anywhere. If a file is not on the server, deleting it loses it for good.

Copy to the server

“Replace existing copies” is on: files already on the server will be replaced.
